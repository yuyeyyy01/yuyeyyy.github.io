## 从插片说起：2D 仿 3D 的传统思路

说到用 2D 面片来仿照 3D 效果，首先想到的就是插片树和插片头发，通过面片的穿插来制造 3D 的体积感。相关思路可以参考《【风格化植物】插片树的 LOD 解决方案》。

除此之外还有几条常见路线：

- **通过偏移 2D 面片速度来模拟纵深效果** —— 见《Shader 入门精要》；
- **通过法线丰富 2D 光影细节** —— 见《高质量 2D 像素游戏渲染方法》。

传统的渲染要么是全 3D（消耗大，美术上限受限于引擎），要么是 2D 纯背景（动态物体无法与背景产生真实的光影和遮挡）。

## 新思路：AI 辅助预渲染 + 全屏世界重建

随着 AI 发展越来越迅速，2D 出图稳定性越来越高。思路是：通过 AI 大模型出**世界法线图**和**深度图**，用 RenderFeature 重构世界坐标，结合一些特定的 trick 来还原类似 3D 游戏的光影信息。

这一套流程应该可以应用于小型摄像机视角固定的**箱庭式游戏**，或者用在**过场动画**中。

整体分三个步骤。

### 步骤一：AI 辅助离线渲染

美术通过三辅二来绘制底色图（Base Color），再通过 AI 生成法线图（Normal）和深度图（Depth）。

**深度图**：使用 WebUI 出图。

**世界法线 AI 图**：通过 nano banana 抽卡，不对的地方局部重绘 + PS 微调。（OpenAI 模型没有尝试……）

### 步骤二：全屏重建

在 Unity URP 中，使用一个全屏 Shader，利用预渲染的深度图还原出每个像素的 3D 世界坐标，然后结合预渲染的世界法线图，接受 Unity 场景中的实时灯光。

**核心**：把离线渲染的 0~1 线性深度转换为正确的 Device Depth，使用 `ComputeWorldSpacePosition` 函数，利用 UV、转换后的深度和相机的逆视锥投影矩阵（`UNITY_MATRIX_I_VP`），凭空计算出这个 2D 像素原本在 3D 空间中的真实世界坐标。

```hlsl
float offlineLinearDepth = 1 - SAMPLE_TEXTURE2D(_OfflineDepthTex, sampler_OfflineDepthTex, uv).r;

float deviceDepth = offlineLinearDepth;
#if UNITY_REVERSED_Z
    deviceDepth = 1.0 - offlineLinearDepth;
#endif

float3 worldPos = ComputeWorldSpacePosition(uv, deviceDepth, UNITY_MATRIX_I_VP);
```

有了世界坐标和法线，Shader 就可以像对待真实 3D 模型一样，计算主光源的漫反射和阴影衰减。

### 步骤三：深度回写

将预渲染的深度转化为设备的硬件深度并强行写入 Z-Buffer。这是让后续 3D 动态物体产生正确遮挡的关键。

在 C# 端，把上面 Shader 画出来的颜色和深度塞进管线：

```csharp
var colorHandle = renderingData.cameraData.renderer.cameraColorTargetHandle;
var depthHandle = renderingData.cameraData.renderer.cameraDepthTargetHandle;

//强制设定渲染目标。
// ClearFlag.None我们直接在现有画面上盖上去，而不清空已有的数据
CoreUtils.SetRenderTarget(cmd, colorHandle, depthHandle, ClearFlag.None, Color.clear);

cmd.DrawMesh(RenderingUtils.fullscreenMesh, Matrix4x4.identity, material, 0, 0);
```

动态物体场景中出现不可见的碰撞体，或者需要接收阴影的复杂几何体，不输出任何颜色、画面上完全不可见，但是开启深度写入和深度测试：

```hlsl
ColorMask 0
ZWrite On
ZTest LEqual
```

这样就得到了一套自定义的 FakeDeferred 渲染管线。
